# RevenueDot MCP

**Connect Claude, ChatGPT and other AI assistants to RevenueDot, the open-source subscription backend that works with the RevenueCat SDK.**

> Status: pre-alpha. Nothing is ready to use yet. See the scope in [revenuedot/revenuedot](https://github.com/revenuedot/revenuedot/blob/main/prd/SCOPE.md).

Planned: an OAuth MCP server with about 12 tools to manage offerings, products and entitlements, look up customers, grant or revoke access, configure webhooks and follow an import from RevenueCat. The tools share their code with the in-app RevenueDot AI agent.

RevenueDot is not affiliated with RevenueCat, Inc.
